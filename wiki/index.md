## Gotchas: pitfalls, by symptom

- [[check-scripts-attached-to-stale-chrome]] — Until 2026-10-29 the headless check scripts used a fixed debugging port (9333) and silently attached to any Chrome already there, so runs drove a stale page; they now start their own Chrome on a free port. (symptom: "Check script reports old behaviour or old screenshots after a code change") · _dev, testing, chrome, mobile_ · verified 2026-10-30
- [[check-scripts-wrote-plays-to-stash]] — A check run without request blocking wrote plays to the real Stash and the reset was refused by the permission classifier; every check script now blocks plays, activity, deletes, get, marker, O and rating writes. (symptom: "Play counts or resume points changed on videos nobody watched") · _testing, stash, privacy, dev_ · verified 2026-10-30
- [[env-key-not-set-at-startup]] — Only the server's dev script reads the repo-root .env; without it (or with `pnpm start`) config.ts throws at startup, and the key is filled in by hand, never copied from another repo's .env. (symptom: "Error: STASH_API_KEY is not set") · _dev, config, secrets_ · verified 2026-10-30
- [[filter-popovers-clipped-in-scroll-row]] — The original filter strip's popovers lived inside an overflow-x row, which clipped everything below the input so searching showed no results; Round 3 replaced the strip with one portalled dialog. (symptom: "Typing in a filter popover shows no results; the dropdown is cut off below the input") · _css, filters, web, ux_ · verified 2026-10-30
- [[grid-column-overflow]] — An implicit CSS grid column grows to its widest child and the layout root clips it, so scene and playlist pages ran off the phone's edge; page grids pin the mobile column with grid-cols-1 (minmax(0,1fr)). (symptom: "Content cut off at the right edge of the phone screen; mobile-check reports horizontal overflow") · _css, mobile, layout, tailwind_ · verified 2026-10-30
- [[k8s-clone-on-side-branch]] — ~/code/k8s was on branch docs/argocd-admin-reset, 215 commits behind origin/main, on 2026-10-29; read flix's manifests with `git show origin/main:infra/flix/...` rather than from the working tree.
